# Online Banking System

## Overview

The **Online Banking System** for **ASTU** is designed to provide students, teachers, and staff members with a secure, efficient way to manage financial transactions. The system allows users to transfer funds, manage payments, apply for loans, view transaction histories, and manage their accounts.

## Features

### 1. **User Registration and Authentication**
- Users (students, teachers, and staff members) can register using their ASTU credentials.
- Authentication through account number and password.
- Registration integrated with the E-student System (currently a placeholder for integration).

### 2. **Account Overview**
- Users can view an overview of their account, including balances, recent transactions, and activity (planned feature, not yet implemented).

### 3. **Fund Transfer**
- Users can transfer funds to other registered users in the system.
- The transfer is processed securely, and users receive confirmation upon successful transfer.

### 4. **Payment Management**
- Facilitates payment processing for various services on campus, such as tuition fees, financial aid, and other expenses.
- Users can pay for campus services like shops, lounges, and other campus facilities.

### 5. **Transaction History**
- Users can view their past transactions, though features like filtering and searching are planned but not yet implemented.

### 6. **Loan and Advance Management**
- Users can apply for loans and advances.
- The loan application is reviewed and approved/rejected by the admin.
- Users can make loan repayments via the online banking system.

### 7. **Admin Management**
- Admins can manage user accounts, including editing, creating, and deleting accounts.
- Admins can review loan applications and approve/reject them.

### 8. **Payroll and Retirement Management**
- This functionality is under development. The system will handle salary calculations, deductions, and retirement benefits for staff.

### 9. **Customer Support Integration**
- Currently, there is no dedicated customer support feature. However, this is planned for future updates.
